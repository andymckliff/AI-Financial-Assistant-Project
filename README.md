# AI-Financial-Assistant-Project
Projet d’assistant bancaire intelligent basé sur l’IA, conçu pour aider les utilisateurs à mieux gérer leur budget, analyser leurs dépenses et recevoir des conseils financiers personnalisés. L’objectif est de rendre la gestion financière plus simple, accessible et pédagogique, notamment pour les jeunes adultes.

## Contexte  
Ce projet a été conçu comme un assistant bancaire intelligent visant à aider les utilisateurs à mieux comprendre et gérer leurs finances personnelles à travers une interface conversationnelle.

## Fonctionnalités principales  
- Analyse des dépenses et du solde  
- Détection automatique d’intentions financières  
- Recommandations personnalisées (budget, épargne, comportements)  
- Interface web interactive (chat, profil, données, historique)  
- API backend connectée à un moteur IA  

## Architecture  
Le projet est structuré en deux parties :  
- **backend** : logique métier, IA, API  
- **frontend** : interface utilisateur HTML/CSS/JS

## Objectif pédagogique et professionnel  
Ce projet n’est pas une application bancaire de production, mais un démonstrateur mettant en avant la compréhension des enjeux UX, produit et techniques liés à l’IA appliquée à la finance.
